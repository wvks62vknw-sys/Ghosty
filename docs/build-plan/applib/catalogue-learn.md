# The Library catalogue: Learning (46 apps)

From the Atlas (Apps tab). Each is an app the owner wants. Give each the truest working core an archetype allows; one that needs its own build is listed in your report, never faked. The "like" names are only for you: never put a brand or app name in any text he sees.

## learn.1 Language Path
A full course in any of thirty languages, Urdu included, with speaking, listening, stories and grammar, a few minutes a day.
Like (for you only): Duolingo, Babbel
- Placement test and a path of units with a visible map
- Exercise types: listen and type, speak and be checked, build the sentence, match pairs, translate
- A grammar tip card per unit
- Short stories and dialogues at his level, read aloud
- Recorded native audio from Lingua Libre and Commons beside the phone voices
- Weak-word review through the cards, with XP, a daily goal and a streak freeze
- A unit works offline once downloaded
Rule: Course text from public sources (Tatoeba, Wiktionary) and the free brain; unit audio downloads only on his tap on Wi-Fi with the size said.
