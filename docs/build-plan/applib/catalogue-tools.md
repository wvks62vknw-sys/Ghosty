# The Library catalogue: Utilities (34 apps)

From the Atlas (Apps tab). Each is an app the owner wants. Give each the truest working core an archetype allows; one that needs its own build is listed in your report, never faked. The "like" names are only for you: never put a brand or app name in any text he sees.

## tools.36 Clock
Alarms, timers, stopwatch and world clock in one Clock, with alarms that still reach you when Ghosty is closed.
Like (for you only): Apple Clock, Google Clock, Alarmy
- Alarms with repeats, labels and snooze, sent as a push when Ghosty is closed
- Wake to his radio station with a fade-in while Ghosty is open
- All timers in one place, kitchen ones included, with presets
- Stopwatch with laps and splits, exported as CSV
- World clock with day and night shown
- Bedside mode: a huge dim red clock, the next alarm and tomorrow's first event

Rule: On a locked iPhone an alarm arrives as a push notification with its sound, not a full ring (a web-app limit), and it says so.
